# E-commerce API

E-commerce is an e-commerce REST API built with ASP.NET Core and Entity Framework Core.

This project was created as a learning project to practice building a backend application with .NET, working with databases, authentication, authorization, relationships, DTOs, repositories, and RESTful APIs.

## Features

* User registration and authentication
* JWT authentication
* User and Admin roles
* Account management
* Product CRUD operations
* Product categories
* Product pagination, filtering, and sorting
* User shopping carts
* Cart item management
* Product comments and reviews
* User-specific comment management
* Comment ratings
* Comment pagination, filtering, and sorting
* Admin user management
* Entity Framework Core
* SQL Server database
* Repository pattern
* DTOs and mapping
* Swagger / OpenAPI documentation

## Technologies

* C#
* ASP.NET Core Web API
* .NET 10
* Entity Framework Core
* SQL Server
* ASP.NET Core Identity
* JWT Authentication
* Swagger / OpenAPI
* Git / GitHub
